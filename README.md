# Портативная платформа для автономного аудита беспроводных устройств

**Тема ВКР:** Разработка портативной платформы для автономного аудита беспроводных устройств на базе Orange Pi Zero 2W

## Описание проекта
Разработка устройства на базе Orange Pi Zero 2W с Kali Linux для проведения аудита безопасности беспроводных сетей. Устройство позволяет выполнять сканирование Wi-Fi сетей, проводить атаки типа deauth, формировать отчеты и вести журнал аудита.

## Структура репозитория
- `diagrams/` - диаграммы UML в формате PlantUML
- `src/` - сгенерированный код Python на основе диаграммы классов
- `report.md` - отчет по выполнению задания
- `images/` - экспортированные изображения диаграмм

## Инструменты
- PlantUML - для создания диаграмм
- Python - язык программирования для реализации логики
- Kali Linux - ОС устройства

## Диаграммы
1. **Диаграмма деятельности (подготовка к защите)** - процесс подготовки ВКР
2. **Диаграмма деятельности (процесс аудита)** - технический процесс работы устройства
3. **Диаграмма вариантов использования** - роли и сценарии
4. **Диаграмма классов** - структура программных компонентов
5. **Диаграмма последовательности** - взаимодействие компонентов при атаке
6. **Диаграмма состояний** - жизненный цикл устройства
7. **Прототип CLI-интерфейса** - схема консольного взаимодействия

## Генерация диаграмм
Для просмотра диаграмм:
1. Установите расширение PlantUML в VS Code или IntelliJ IDEA
2. Откройте любой файл `.puml`
3. Используйте предпросмотр (Alt+D в VS Code)

Или используйте онлайн-редактор: https://www.plantuml.com/plantuml/uml/
